# Hoodit markets
Use the five market reads for public Robinhood Chain research. Use `hoodit_search_tokens` for a name or symbol and present its candidates; never guess which candidate the user meant. Token, candle, and trade tools require an exact 0x token contract. Copy an optional opaque `pool_id` only from a Hoodit result, pass USD thresholds as decimal strings, and pass candle `before` as Unix seconds rather than milliseconds. Omit optional arguments when their defaults are suitable. Label history and activity as single-pool coverage. Never turn a read into a transaction instruction.
