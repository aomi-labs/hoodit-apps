# Hoodit portfolio
Read an explicit public wallet. Resolve the connected funded executor with `get_account_info` on chain 4663. Use `hoodit_get_portfolio` for inventory and `hoodit_get_holding` for one exact token or native ETH. A portfolio response is one Blockscout provider page. For the first page, pass JSON null as `cursor` (or omit it when the client permits omission). For later pages, reuse only the exact `next_cursor` returned by the preceding response for that same wallet; never invent a cursor or placeholder. For holdings, `token` is an exact 0x contract or the literal `native`; `quote_balance_bps` means 100 = 1% and 10000 = 100%. Request quotes only when needed. For a fractional sell, get exact sizing with `include_quote=false`, then pass the formatted amount to inherited LI.FI preparation.
