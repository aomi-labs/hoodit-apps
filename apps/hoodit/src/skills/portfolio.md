# Hoodit portfolio
Read an explicit public wallet. Resolve the connected funded executor with `get_account_info`. A portfolio response is one Blockscout provider page. For the first page, omit `cursor` entirely: never send JSON null, an empty string, or the string `"null"`. For later pages, reuse only the exact `next_cursor` returned by the preceding response for that same wallet. Request quotes only when needed. For a fractional sell, get exact sizing with `include_quote=false`, then pass the formatted amount to inherited LI.FI preparation.
